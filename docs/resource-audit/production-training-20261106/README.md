地图补查：4/19/31/38各自的地面贴图、背景、天空共12项Resources入口均已解析。4项地面贴图递归检查通过；8项背景/天空闭包在MonoBehaviour自定义字段处遇到旧Unity类型树解析限制（对象84字节，工具仅按公共类型树消费24字节），不能把它们判成缺文件，也不能宣称地图完整依赖已全部验证。8个对象的GameObject与MonoScript指针已按旧版公共头格式解析，全部指向存在的LevelBackground脚本；仍有每个60字节自定义字段未按脚本结构解析。详见map-table-evidence.json。

## 证据口径

- production-snapshot.json：生产revision、实际开关、12关有效主表/地图及敌人记录，不含账号或连接凭据。
- production-http-and-bundle-audit.json：当前生产HTTP、文件、导出、具名贴图、递归依赖证据，是当前下载资源结论的依据。
- map-table-evidence.json：原APK MapTable、地图资源路径、递归结果及8项旧MonoBehaviour解析限制。
- local-source-and-scene-audit.json：本地Resources绑定、来源哈希、原APK场景信息。
- results.json / graph.json / 全部加载需求.csv：使用旧加载链解析器针对12关重跑的原始与当前需求对照，当前需求取生产有效敌人记录。
- 旧资源索引差异参考.csv及summary.json中的142条“缺口”是旧catalog尚未收录后续生产兼容包的差异；不能当作当前142项缺失。下载包以本次生产HTTP与包内检查覆盖判定；缺少同名全局材质缓存按原代码允许为空，实际模型材质在包内依赖闭包核查。

## 复现
