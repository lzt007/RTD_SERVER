## 数据版本线索

- 主要资源包自身的Unity引擎版本为5.3.5p8；少数历史图集带4.6.5p3/4.3.4f1标记。Unity版本不是游戏APK版本。
- Icon/AI目录包含多代V1028至V1036及V5700、V5800……V6900、V7000资源目录，证明是跨代资源集合，不能视为单一版本快照。V7000提示7.0代资源（推测），不能由此确定7.0.1或更精确APK版本。
- quest包含4124个msgpack关卡响应，归档中部分关卡条目时间为2017-03-16。该时间只能作为归档记录线索，不能独立证明APK版本；响应可能含会话字段，未将其原文写入报告。
- 未发现足以唯一绑定APK版本的已核实数据字段；结论是“包含V7000代资源、主要由Unity5.3.5p8构建的混合历史数据”，不能认定两个附带APK之一与之匹配。
