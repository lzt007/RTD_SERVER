# 按原客户端加载链重审资源缺口

本表是新素材全面纳入前的旧来源基线，历史上替代旧209项清单；当前状态见[最新审计入口](../README.md)，下面218项等统计不是现生产缺口。范围为228个可开放主线、已支持及已完成修复活动关卡（修复开关开启，不等同玩家已解锁或活动已排期）。逐关卡加载敌人表全部18普通槽位及Boss/Death槽位；原始引用与当前替代配置分开核对。图片是解包的UV贴图，不是3D渲染。

## 覆盖证据

- 全新内容索引：2709份去重内容、2708个序列化文件、225804个对象（包括无名对象），解析错误0。
- 90个预载文件全部解析；90个均匹配到内容哈希一致的APK内嵌预载副本。__info等缓存元数据不计入这90个资源文件。
- APK内所有assets条目均有覆盖记录；Unity对象文件解析，其他条目标记为非Unity对象数据。程序集代码、原生库等不是贴图缺口判定对象。
- 2250条APK Resources绑定均通过外部FileID/PathID解析到实际对象，而非仅匹配路径字符串。
- 对关卡可达的180个资源根追踪6573个对象，包括模型、骨骼、材质、贴图、动画和特效；本次静态序列化指针检查未发现悬空引用。引擎自带资源单独识别，不误判为缺失。

## 缺口统计（避免重复计数）

- 原始模型/贴图缺口218项：模型138项、贴图80项。
- 相对旧209项清单新增9项，见相对旧表新增项.csv；其中书本是先前遗漏的加载依赖，普通新增项来自整张敌人表预加载。
- 新增9项具体为5个角色地图书本及4个楼梯/移动地板模型；普通敌人原始模型/贴图仍为209项。本次独立加载链核对没有额外确认普通物种模型。
- 本地缺少132个原始下载包；这些包内模型/贴图已计入上述缺口，不把“缺包”和“缺模型”简单相加。
- 当前替代配置的直接模型、贴图、角色本体、已映射动作及攻击效果均找到资源对象。仍使用重建包恢复的书本：ms00_book_el_01、ms00_book_el_02、ms00_book_el_03、ms00_book_el_05、ms00_book_el_06。重建存在不等于原始美术已恢复。
- 空动作null是客户端可容忍的空动作；同名Material缓存未命中也被代码判空保护，实际渲染材质从模型依赖核对。这两类不直接计作必须补绘资源。

## 物种复核

螃蟹、鸟、狼、蝎等会同时检查包导出名、APK完整Resources路径、所有实际对象名及模型递归依赖。更正：当时旧来源仅命中蝎/狼动作，后续新资源已找到330系列狼和四属性ms01_sco_*_02蝎子的实际模型与贴图，并发布同族兼容包；缺等级采用低等级放大。不能沿用旧未命中结果认定现有素材仍缺失。完整对象及来源CSV便于交叉核验。

## 加载链依据与限制

原始DLL导出定义包含包版本、本地白名单、角色敌人类型、MotionAssign动作索引、MotionData文件名、ConvertKindToCategory、EnemyAttackEffectAssign。EnemyArrangeTable读取全部槽位；普通敌人非Boss在动作列2提前返回，角色书本方向分支另列条件。na在EnemyData构造函数转换为空贴图，不当作真实文件名。

包身份按实际包文件名和ast_模型的包导出确认；不能以其他包中的同名对象认定目标包可加载。原始资源与reconstructed来源分开。Resources外部指针按同APK上下文优先解析；全部2250条已唯一解析。

这是静态加载链与对象依赖核对，不是Android实机下载日志。尚未验证Unity实际URL/版本缓存键命中、目标HTTP可达、运行时组件行为，以及玩家队伍触发的全部共享技能/声音/场景资源。动作的BOOK_SYMBOL与朝向分支按可能条件保留；素材存在不代表所有动画或视觉显示已实机验证。结论限于当前工作区与上述敌人加载路径，不对未提供的资源包作不存在断言。

## 文件入口

- 资源缺口总览.html：可筛选缺口、已有物种图鉴及贴图预览。
- 决策缺口表.csv：用于复用/补绘决策。
- 全部加载需求.csv：含原始和当前两种口径，保留加载条件。
- 90个预载文件核对.csv、APK资源覆盖.csv、APK_Resources绑定核对.csv：覆盖及路径证据。
- 全部资源对象.csv、资源来源.csv：包括未命中物种关键词和无名对象的完整清单。
- 递归依赖待核实.csv：本轮无悬空序列化指针。
