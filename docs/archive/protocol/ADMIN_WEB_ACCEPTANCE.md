## 使用

- 卡池管理：开关三个固定卡池，编辑名称、日程、单位、等级和权重；概率随权重计算。抽数和消耗沿用既有规则。
- 活动管理：创建、编辑、启停、删除活动，编辑日程、关卡和掉落。添加多层入口会补齐必需子层；未验收关卡仅允许保存关闭配置。
- 单位/关卡输入框提供原主表目录；输入 ID 或检索名称后选中对应 ID。
- 角色选择旁提供原版头像，切换ID时同步更新，点击头像可放大查看；卡池概览也有缩略图。卡池与活动掉落共用此能力。
- 默认保留原始掉落；勾选“使用本地规则覆盖”才编辑单位、等级范围、权重、空掉落、属性经验与允许的活动积分。原始掉落缺失必须明确覆盖，不能静默视为原版不掉落。
- 时间使用浏览器本地时区；留空表示不限制，结束边界不包含。开关表示启用意愿，卡片“开放中/时间外/已关闭”表示上次读取时的状态，跨日程边界后点击刷新。
- 保存立即持久化并作用于后续请求；游戏客户端缓存的活动列表可通过返回标题刷新。已存在战斗不据此宣称重新结算。
- 所有页面写入包含配置版本。并发冲突保留当前草稿，需记下改动、关闭并刷新后重新编辑；不会自动覆盖新配置。离开未保存表单会提示确认。
- 无外部 CDN、构建步骤或后台登录；沿用既有仅监听本机回环地址的运行方式。
