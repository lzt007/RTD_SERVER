# 好友流程补齐计划

目标：沿用现有协议与事务，修复战后 NPC 申请异常，开放真实陌生账号助战与战后申请。

依据：归档 protocol/index.json 的 ComManager 请求构造与响应分支、rules/LOCAL_FRIENDS.md 的既有取证。当前环境未找到原 DLL，不声称重新反编译或实机验收。

1. 写回归用例并观察失败：NPC 不触发申请；陌生账号列表、借用后申请及接受；陌生借用基础5点、好友10点，按入场身份冻结。
2. NPC 标为已建立助战关系以避免客户端发出不可完成的申请；防御性处理旧客户端向0申请，返回客户端已识别的8706。
3. 服务端提供最多20个无关系的其他本地账号，排除自己和待处理申请；单层、多层复用助战资料构造。陌生账号成功借用基础5点，提供者仍10点（本地政策），每日有向对只领取一次。
4. 保留既有申请/搜索/批量接受/删除及双方原子事务；定向测试后全量回归，审查暂存内容，分阶段提交。既有部署脚本改动不纳入提交。
