# 全种族外观持续恢复计划

用户明确要求逐种族重审已有替代，不因已有替代而跳过。来源覆盖旧APK、旧缓存、新APK、新缓存；精确原素材优先，不能精确满足时按种族、属性、等级排序。缺等级用同族低等级适度放大，缺属性染色；确无同族才跨种族，Boss相同。

1. 建立四来源模型/贴图外观清单，与原始敌人主表及当前126+7兼容包交叉审计。
2. 按种族生成恢复决策：来源、原/推测、属性、等级、尺寸、缺口及骨架兼容证据。
3. 先狼、史莱姆、蝎子，再其他道中种族，最后逐Boss家族；已实机验证素材保护原件，但可制作更准确独立候选。
4. 每族逐导出闭包、原生激活、独立CAB、动作/网格/贴图/透明度回读；颜色和尺寸单独验证。
5. 各族候选通过后合并清单，比较正常关卡和所有非外观字段；保留备份和逐族结果，不宣称离线即实机验收。
